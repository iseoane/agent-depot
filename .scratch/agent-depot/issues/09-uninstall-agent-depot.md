# Uninstall Agent Depot with data choices

Status: completed
Blocked by: 08 Replace or remove Sources safely

## What to build

Let users independently choose whether to remove the persistent CLI, managed Skills, and catalog or configuration data. Preserve managed Skills and user data by default. Delegate the CLI package lifecycle to the package manager.

## Acceptance criteria

- Users can independently choose whether to remove the persistent CLI.
- Users can independently choose whether to remove managed Skills.
- Users can independently choose whether to remove catalog and configuration data.
- Managed Skills are preserved by default.
- User data is preserved by default.
- The CLI package lifecycle remains delegated to the package manager.
