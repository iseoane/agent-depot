## Deviations

1. Package panels (`package-approve`, `package-confirm`, `package-forget`) now render alone, like the App panels, instead of under the Catalog/Installations list (the list rows above were not counted in the viewport height). Titles changed from "Confirmation" to `Package approval`, `Package <action> confirmation`, `Forget Package selection`.
2. `y` is gated on the last row for all three Package panels (like App/Updates); the footer question reads `Scroll to end before y; n cancels.` until then. Any test pressing `y` now pages first via `tests/package-panel.ts` (`pageToQuestion`, `pageToEnd`, `pagedRows`). That is new behavior, not an accommodation.
3. The shell footer (`app.tsx`: `Enter submit · Esc cancel · y/n confirm · space toggle`) is unchanged; the paging keys are in the panel legend (`Review N of M · arrows/Pg page`), as in the Updates preview. Acceptance "footer shows them" is met at the panel legend only.
4. Profile export name stage is **elided, not paged**: keys type into the name, so it cannot take paging keys. Folder and Destination keep first and last rows with `… N more rows`/`…`, the typed name keeps its tail so the cursor stays visible, long errors keep first and last rows. The full destination is reachable on the paged confirmation that follows (asserted in `tui-profile.test.tsx`).
5. File picker: new compact mode (one clipped path line, one legend line, filter note clipped to one line) when the roomy chrome leaves no list row; the full-path view (`p`) now pages with j/k/PgUp/PgDn (its footer now reads `j/k scroll · p hide path · Esc back`). In the test I removed `listHeight={6}` as well as the `/picker` stub. The existing 16-row test "the picker fits a wrapped long directory…" was restructured: it asserts the roomy hints at 30 rows and the compact legend at 16, and reads the full path across pages, because at 16 rows the old layout only fit by ignoring the header the picker budgets for.
6. Host-only note assertions in `tui-packages` and `tui-catalog-packages` now use `squash`: the shared preview wraps by grapheme, not by word, so "manages it" can break inside a word.
7. Scope extension: the Profile export/import confirmation paged only up to the source-line count; it now pages over wrapped rows (`previewViewport` total and height). Without it the long destination at the top could not be scrolled past. Import/export `y` is still not gated on the last row (both have a range indicator, so acceptance 2 holds by indication; import installs things, so the coordinator may want to gate it in a follow-up).
8. Out-of-scope test fix: `tests/tui-installations-unmanaged.test.tsx` "would dangle" asserted across a wrapped line and failed on baseline at a 42-char TMPDIR; it now matches the squashed text. It is in commit `cd5662c`, whose message does not mention it (no amend: a force push was not authorized).
9. Long paths are now part of the fixtures (journey base directory name, profile `picker` name, picker test dir) so the tests do not depend on the machine's TMPDIR. I could not reproduce "the brief's rows: 60 was for Windows" locally; Windows CI is green without it.
